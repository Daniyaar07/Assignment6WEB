# Assignment 6

## Description
This project demonstrates basic jQuery methods, effects,DOM manipulation, and animations.

## Project Structure
- index.html - Home page
- part1.html - jQuery Basics
- part2.html - jQuery Effects

2. Use the navigation bar to switch between parts.
